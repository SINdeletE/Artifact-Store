# PPO

## Название проекта
Приложение для продажи артефактов во внутриигровом магазине

## Краткое описание идеи проекта
Проект представляет собой backend для внутриигрового магазина артефактов. Для данного проекта будет спроектирована база данных для покупки артефактов и для их храненения в инвентаре. Для взаимодействия с базой данных будет предоставлено API.

## Краткое описание предметной области с перечислением основных сущностей предметной области
Предметная область - электронная коммерция. 

Основные сущности предметной области: Персонаж, Баланс, Валюта, Лоты для продажи (Валюта-Артефакт), Артефакт, Все артефакты в инвентарях  (Персонаж-Артефакт), Транзакции по покупкам артефактов  (Баланс-Артефакт-Валюта).

## Пользовательские сценарии
### Сценарий 1
1) Пользователь выбирает персонажа
2) Пользователь, играя за определённого персонажа, просматривает магазин артефактов
3) Пользователь, играя за определённого персонажа, нажимает кнопку "Купить артефакт" и отправляет запрос на покупку артефакта
4) Проверяется балансы пользователя: если валюты недостаточно/баланса по необходимой валюте нет - отказ
5) Данные о покупке сохраняются в таблице транзакций
6) Артефакт удаляется из магазина
7) Артефакт добавляется в инвентарь персонажа
8) Пользователь выходит

### Сценарий 2
1) Модератор заходит
2) Модератор просматривает продаваемые артефакты
3) Модератор выходит

### Сценарий 3
1) Администратор заходит
2) Администратор просматривает магазин артефактов
3) Администратор удаляет артефакт из магазина
4) Администратор просматривает артефакты в инвентарях
5) Администратор добавляет артефакт в инвентарь пользователя
6) Администратор выходит

## Описание типа приложения с точки зрения взаимодействия с пользователем и выбранного технологического стека
Сайт-имитация игры, имеющая только механики, относящиеся к артефактам (покупка и т.д).

*Архитектура*: Монолитная, MVVM (Frontend), MVC (Backend)

*Backend*: ASP.NET C#, Entity Framework Core

*Frontend*: Blazor, Razor Pages

*Database*: PostgreSQL (миграция на MongoDB), Redis

*Migrator*: MongoDB Relational Migrator
